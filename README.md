# HR-Analytics-Dashboard-Decoding-Employee-Tenure-Turnover

## 🎯 Project Objective

The goal of this **HR Analytics Dashboard** is to decode employee tenure and turnover patterns through data-driven insights.  
This dashboard enables HR teams to identify **where and why attrition happens**, understand workforce demographics, and uncover key retention opportunities.

By visualizing metrics such as **Attrition Rate, Tenure, Education Level, Age Group, and Payment Tier**, the project transforms raw HR data into **actionable insights** that support smarter, data-backed HR decisions — improving employee engagement and reducing turnover.
